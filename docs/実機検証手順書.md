# P1 実機検証手順書（iPhone / Android）

対象: `generate_qr.py` が生成する `output/meishi_qr.png`（vCard 3.0直埋め込みQR）
実施者: Maiko
関連タスク: 「P1: 実機検証（iPhone＋Android・Maiko実施）」

## 検証する前提リスク（仕様書の保留点）
1. iPhone/Android実機でvCard QRが2〜3タップで連絡先追加できるか
2. 日本語（漢字氏名・会社名）が文字化けしないか
3. 誤り訂正レベルH(30%)×データ量300バイト以内の組み合わせで、スキャンの読み取りやすさに問題がないか

## 事前準備
1. `profile.json.example` をコピーして `profile.json` を作り、Maiko自身の実データ（氏名・電話・メール・会社・肩書き・URL）を入力する
2. `.venv` を有効化し `python generate_qr.py` を実行する
3. `output/meishi_qr.png` が生成され、コンソールに「生成完了」とvCard文字数が表示されることを確認する
4. 生成されたPNGをスマホで見られる状態にする（画面に表示 or 印刷 or チャットで自分に送る）

## 検証手順

### iPhone
1. 標準カメラアプリを起動し、QRコードにかざす
2. 画面上部/下部に出る通知をタップする
3. 連絡先プレビュー画面が表示されるまでのタップ数を記録する（目標: 2〜3タップ）
4. プレビューに表示された氏名・会社名・肩書きに文字化け（□や?、意味不明な記号）がないか確認する
5. 電話番号・メールアドレス・URLが正しい値で表示されているか確認する
6. 「連絡先を作成」をタップし、実際に連絡先アプリに保存されることを確認する

### Android
1. 標準カメラアプリ（Google純正 or 端末プリインストール）でQRコードにかざす
2. 通知またはオンスクリーンのリンクをタップする
3. 連絡先プレビュー〜保存までのタップ数を記録する
4. iPhoneと同様に文字化け・値の正しさを確認する
5. 機種によっては標準カメラがQR内のvCardを認識しない場合がある。その場合はGoogleレンズ / 別のQRリーダーアプリでも試し、機種依存かどうかを記録する

### スキャンのしやすさ
- 画面表示・印刷それぞれで、認識までにかかった時間・距離・照明条件による差を記録する
- 認識に失敗した場合、再スキャンで解決するか、恒常的に失敗するかを記録する

## 文字化けが発生した場合の対応
UTF-8プレーンテキストのままでは一部Android端末で文字化けする可能性がある（仕様書の保留点）。発生した場合は以下をBenに差し戻し、対応方針を検討する：
- vCardの先頭に `CHARSET=UTF-8` を明示する
- 各フィールドをQuoted-Printableエンコードに切り替える

## 判定基準
- 両OSで2〜3タップ以内に連絡先追加でき、文字化けがなければ「合格」
- 一方のOSのみ問題がある場合は「条件付き合格」とし、保留点として記録した上で運用可否をMaikoが判断する
- 両OSで文字化け・タップ数超過が発生する場合は「不合格」とし、Benに設計差し戻し
